# skills/ — AI 技能目录

这个文件夹用来放 AI 的「技能」模板。**一个技能 = 一个文件夹**，AI 会读取每个技能，把它们当作可执行的分析流程。

## 结构

```
skills/
  descriptive_stats/skill.md     # 技能：描述性统计
  compare_two_groups/skill.md    # 技能：两组比较
  ...
```

每个技能文件夹里只放一个 `skill.md`：

```markdown
# 描述性统计          ← 第一行 `# 显示名`（AI 窗口下拉里显示这个名字）
这里写这个技能的完整分析流程，AI 会照着做…  （其余内容 = 给 AI 的流程/模板）
```

## 全局技能 vs 工程内技能

- **全局技能** = 这个 `skills/` 目录里的技能 → 对所有工程可用。
- **工程内技能** = 某个**工程文件夹**里的 `skills/` → 只对该工程可用（同名会覆盖全局的）。

两边都会合并显示在 AI 窗口的「Skill / 技能」下拉里。

## 添加 / 删除

- **添加**：新建 `skills/<名字>/skill.md`（第一行写 `# 显示名`，下面写流程）。
- **删除**：删掉那个技能文件夹。
- 动完后**刷新网页**，AI 窗口「Skill」下拉会自动出现 / 消失。

## 不指定技能时

你不指定具体技能的话，AI 会**根据当前任务自己挑最合适的一个**来用。
